# Assets

Put your logo files here: `esnet_logo.png`, `lbl_logo.png`, `cborg_logo.png` (any size ≥ 64px).

Get them from official sources:

- **ESnet**: es.net → "Logos, Maps, and Acknowledgments" (media@es.net per the 2025 ESnet Brand Guidelines)
- **Berkeley Lab**: lbl.gov (brand/communications office)

No logos ship in this repo (git-ignored). The renderer draws a neutral letter icon if a file is missing.
